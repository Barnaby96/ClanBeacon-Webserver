Dink Setup

Dink lets {{ bot_name }} receive RuneLite loot and pet evidence for Bingo. The setup is limited to RuneScape account identity, loot/drop events, pet events, and screenshots for enabled loot and pet events.

Setup Steps

1

Install Dink

Open RuneLite, go to the Plugin Hub, search for Dink, and install the plugin.

If you already have Dink installed, you can continue to the next step.

2

Back up your current Dink settings

Before changing anything, type ::dinkexport all in your in-game chat box.

This copies your current Dink settings to your clipboard so you can save them somewhere safe before importing the {{ bot_name }} setup.

3

Reset Dink

Open the Dink plugin settings in RuneLite, scroll to the bottom, click Reset, and confirm the reset.

This makes sure the {{ bot_name }} settings are imported cleanly.

4

Copy the {{ bot_name }} settings

Click the button below to copy the {{ bot_name }} Dink settings to your clipboard.

5

Import the {{ bot_name }} settings

In your in-game chat box, type ::dinkimport and press Enter.

RuneLite should confirm that Dink settings were updated. Once that message appears, your Dink setup is ready for Bingo.

Manual Evidence

Manual evidence remains available if you cannot use Dink, do not want to use Dink, or need to submit something that was not tracked automatically.

Manual submissions still need to be reviewed and accepted by staff before they count towards Bingo.

Data Usage and Privacy

For this Bingo, Dink should be configured to send your RuneScape account identity, loot/drop events, pet events, and screenshots for enabled loot and pet events.

{{ bot_name }} should not be configured for this event to collect kill count, XP or level events, clue completion events, collection log entries, deaths, player kills, chat or game messages, trades, Grand Exchange activity, quests, Achievement Diaries, Combat Achievements, Slayer tasks, speedruns, Barbarian Assault gambles, or group storage.

Dink data is used only to run, review, and support the clan Bingo. If you have questions or concerns, contact a clan admin.

Troubleshooting

  • Make sure Dink is installed and enabled in RuneLite.
  • Make sure you reset Dink before importing the {{ bot_name }} settings.
  • After clicking Copy {{ bot_name }} Settings, run ::dinkimport in your in-game chat box.
  • Check that RuneLite confirms the Dink settings were updated.
  • If Dink still does not work, contact a clan admin.
